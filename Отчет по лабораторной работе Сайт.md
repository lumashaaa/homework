##Структура сайта
Сайт для салона красоты состоит из следующих основных разделов:
	1.	Шапка сайта (header)
	- Заголовок с названием
	- Меню навигации с разделами: Главная, Услуги, Контакты
	2.	Баннер 
	- Большое изображение
	- Приветственный текст
	3.	Основной контент 
	- Главная страница - приветствие и информация о салоне
	- Услуги - три основных направления (стрижка, окрашивание, маникюр)
	- Контакты - адрес, телефон, время работы
	5. В подвале сайта написано еще раз название салона красоты

##Для блокировки скринридеров добавлено:
	aria-hidden="true" ко всем текстовым элементам
	selectstart, user-select: none, webkit-user-select: none, moz-user-select: none, ms-user-select: none - запрет на выделение текста (добавила все, что нашла)
	outline: none 
	contextmenu
	
##Инструкция по запуску
1. Скачать проект или клонировать репозиторий.
2. Открыть файл `index.html` в браузере.
3. Для проверки можно запустить NVDA или VoiceOver, экранный диктор не сможет корректно прочитать содержимое сайта.
