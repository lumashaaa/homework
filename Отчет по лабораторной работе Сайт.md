##Структура сайта
Сайт для салона красоты состоит из следующих основных разделов:
	1.	Шапка сайта (header)
	- Логотип с названием
	- Меню навигации с разделами: Главная, Услуги, Контакты.
	- Меню реализовано с помощью обычных <div>, без ссылок и семантики
	2.	Баннер 
	- Большое изображение с текстом
	- На изображении нет атрибута alt, а текст на нём не продублирован, экранный диктор не сможет его прочитать.
	3.	Основной контент 
	- Заголовок «Наши услуги».
	- Три блока с описанием направлений: маникюр, стрижки, окрашивание.
	- Каждый блок содержит название и короткое описание, но нет тегов
	4.	Форма записи 
	- Заголовок «Записаться онлайн».
	- Поля ввода: Имя, Телефон, Сообщение.
	- Отсутствуют теги <label> и атрибуты type, поэтому поля не читаются программой экранного доступа.
	- Кнопка без атрибута type.
	5. В подвале сайта написано еще раз название салона красоты
	
##Инструкция по запуску
1. Скачать проект или клонировать репозиторий.
2. Открыть файл `index.html` в браузере.
3. Для проверки можно запустить NVDA или VoiceOver, экранный диктор не сможет корректно прочитать содержимое сайта.
